# 🎨 SwatchBox
> An interactive design token studio, live component sandbox, and instant CSS/Tailwind config exporter built with React, TypeScript, and Zustand.

## ✨ Features

- **Dynamic Token Engine:** Real-time manipulation of colors, typography scales, and spacing tokens.
- **Live Component Sandbox:** Instant preview of UI components (buttons, badges, cards, inputs) reacting to state changes.
- **One-Click Exporter:** Generate copy-ready CSS `:root` variables, Tailwind extension objects, or raw JSON tokens.
- **Preset Switcher:** Switch seamlessly between thematic presets.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/whitgunt77/swatch-box.git](https://github.com/whitgunt77/swatch-box.git)
   cd swatch-box
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack

⦿ **Frontend:** React, Vite, TypeScript
⦿ **Styling:** Tailwind CSS, CSS Custom Properties
⦿ **State Management:** Zustand
⦿ **Icons:** Lucide React
